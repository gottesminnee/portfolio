# BLUSH CLUB — концепт-магазин крафтовых напитков

## Запуск
Открой `index.html` в браузере. Для разработки удобно использовать VS Code и Live Server.

## Функции
- Каталог, категории, сортировка и поиск
- Карточки товаров с описанием и составом
- Корзина: добавление, удаление, изменение количества, подсчёт суммы
- Избранное
- Сохранение корзины и избранного в LocalStorage
- Демо-оформление заказа с HTML-валидацией
- Демо-подписка на рассылку
- Возрастной экран 18+
- Адаптивная верстка и мобильная навигация

## Важно
Это учебный frontend-прототип. Алкогольные позиции показаны только как демонстрационные товары: добавить их в корзину и купить нельзя. Заказы, подписки и персональные данные никуда не отправляются; платежи и доставка не подключены.

Фотографии и шрифты загружаются с Unsplash и Google Fonts, поэтому для них нужен интернет.
